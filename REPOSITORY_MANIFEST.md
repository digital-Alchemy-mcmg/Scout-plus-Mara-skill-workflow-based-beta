## Corrected Runtime Ontology

Candidate Core is first-class and owns identity/biographical subject information.

Evidence Registry has five domains:

- Work History
- Education & Technical Competency
- Creative Works & Projects
- Psychometric & Cognitive
- References / Publications / Testimony / Observed Behavior

`IDENTITY` is not an evidence domain.

## Validation Commands

- `npm test` — deterministic architecture invariant checks.
- `npm run validate:architecture` — same architecture validator explicitly.
- `npm run lint` — TypeScript no-emit check.
- `npm run build` — production client/server build.

A successful build is not sufficient for architecture acceptance.

## Protected Unresolved Decisions

This repair does not decide active-wall count, Semantic Band continuation, exact MARA Exhaust policy beyond explicit non-bind states, receptor-selection ownership, formal Spatial DNA population location, or the long-term repository role. Those boundaries remain documented rather than guessed.
